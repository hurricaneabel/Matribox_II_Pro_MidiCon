# Arquitetura do Projeto

## matribox_core.py

Responsável apenas por comunicação MIDI.

Funções:

* send_cc()
* send_pc()
* go_to_preset()
* set_stomp_mode()
* set_preset_mode()
* ctrl()
* module_on()
* module_off()
* tuner_on()
* tuner_off()
* set_bpm()
* close()

---

## matribox_state.py

Responsável por armazenar o estado interno do software.

Armazena:

* banco atual
* preset atual
* modo atual
* estado dos módulos
* estado do afinador

Importante:

O state NÃO lê informações da pedaleira.

Ele apenas mantém o estado conhecido pelo software.

---

## matribox_controller.py

Camada intermediária.

Responsável por:

* atualizar state
* chamar core
* abstrair a lógica da aplicação

Fluxo:

GUI → Controller → Core → MIDI

# Seleção MIDI de Presets

Utiliza:

```text
CC0
Program Change
```

## Bancos 01 a 30

```text
CC0 = 0
PC = 1 até 120
```

## Bancos 31 a 60

```text
CC0 = 1
PC = 1 até 120
```

Fórmula validada:

```python
pc = ((bank_inside_group - 1) * 4) + letter_index + 1
```

# CTRLs

Funções:

```text
CTRL1
CTRL2
CTRL3
CTRL4
```

MIDI:

```text
CC71 = CTRL1
CC72 = CTRL2
CC73 = CTRL3
CC74 = CTRL4
```

Importante:

Os CTRLs NÃO representam efeitos específicos.

Eles executam as funções configuradas pelo usuário dentro do preset.

Exemplo:

Preset 01C:

CTRL1 = Overdrive
CTRL2 = Cab
CTRL3 = Reverb
CTRL4 = Delay

Outro preset pode possuir funções completamente diferentes.

# Controle Direto dos Blocos

Validado em hardware.

CCs:

```text
CC43 = Bloco 1
CC44 = Bloco 2
CC45 = Bloco 3
CC46 = Bloco 4
CC47 = Bloco 5
CC48 = Bloco 6
CC49 = Bloco 7
CC50 = Bloco 8
CC51 = Bloco 9
CC52 = Bloco 10
CC53 = Bloco 11
CC54 = Bloco 12
```

Valores:

```text
0   = OFF
127 = ON
```

Importante:

O controle é feito pela POSIÇÃO do bloco na cadeia.

Não pelo tipo do efeito.

Exemplos:

```text
Bloco 1 = Compressor
Bloco 1 = Amp
Bloco 1 = Delay
```

Sempre será controlado por:

```text
CC43
```

# BPM Direto

CCs:

```text
CC68

```

Faixas:

```text
40 a 127 BPM
CC68 = 0
CC69 = valor BPM
```

```text
128 a 255 BPM

CC69 = BPM - 128
```

```text
256 a 300 BPM
CC68 = 2

```

Validado.

Mudança instantânea.

Não necessita troca de preset.

# Tap Tempo

CC:

```text
CC70
```

Valor:

```text
127
```

Validado.

O BPM é calculado pelo intervalo entre os taps.

Fórmula:

```python
intervalo = 60 / bpm
```

Exemplos:

```text
60 BPM  = 1.000 s
120 BPM = 0.500 s
180 BPM = 0.333 s
```

---

# Descobertas Importantes

1. O comportamento real da unidade é mais confiável que o manual.

2. CC29 apresentou comportamento invertido em relação à interpretação inicial.

3. Os blocos 1-12 são indexados pela posição na cadeia.

4. O software atualmente envia comandos MIDI mas não recebe o estado real da pedaleira.

5. O estado exibido na aplicação deve ser tratado como estado conhecido pelo software e não necessariamente como estado real do hardware.

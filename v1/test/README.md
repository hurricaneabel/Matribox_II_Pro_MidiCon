# Matribox II Pro MIDI Controller

Python MIDI controller for Matribox II Pro.

## Features

* Preset selection
* Bank navigation
* Stomp/Preset mode switching
* Effect block control
* Expression pedal control
* Quick Access knob control
* BPM and Tap Tempo
* Tuner
* Looper
* Drum Machine

## Requirements

* Python 3.12+
* mido
* python-rtmidi

## Installation

```bash
pip install mido python-rtmidi
```
